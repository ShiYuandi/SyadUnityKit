# SYAD Unity Kit 文档

适用版本：`0.2.0`

SYAD Unity Kit 当前包含两个运行时模块：

- `Syad.UnityKit.UI`：页面目录、层级、生命周期、缓存与释放管理。
- `Syad.UnityKit.Input`：强类型输入命令转发、启停与全局冷却。

仓库中的 `Assets/Demo/UI` 和 `Assets/Demo/Input` 提供可运行示例。通过 Git URL 安装 UPM 包时，不会把这些 Demo 自动导入目标项目。
